# StudyHive Lo-Fi Audio Tracks

This folder stores the local audio tracks for StudyHive's Lo-Fi player.

## Included Royalty-Free Tracks (CC0 / Public Domain)
1. `cozy-rain-chords.mp3`
2. `honey-library-lofi.mp3`
3. `warm-hearth-chill.mp3`
4. `midnight-study-flow.mp3`

## How to Add Your Own Music
1. Copy any `.mp3` or `.ogg` file into this directory (`client/public/audio/tracks/`).
2. Add or edit the track entry in [`client/src/config/audioCatalog.js`](../../src/config/audioCatalog.js).
3. The player will instantly recognize and play your custom audio files!
